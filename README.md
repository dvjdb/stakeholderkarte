# Politischer Atlas – GitHub-Version

Enthalten:
- index.html
- admin.html
- data/abgeordnete.json

Einmalig alle Dateien und den Ordner `data` in das GitHub-Repository hochladen.

Spätere Änderung:
1. Die veröffentlichte URL mit `/admin.html` öffnen.
2. Eintrag bearbeiten oder hinzufügen.
3. `JSON herunterladen` anklicken.
4. Auf GitHub im Ordner `data` die Datei `abgeordnete.json` ersetzen.
5. `Commit changes` anklicken.
6. Nach kurzer Zeit ist die öffentliche Karte aktualisiert.
